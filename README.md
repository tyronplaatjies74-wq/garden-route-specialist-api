# Garden Route Specialist

Garden Route specialist API for Knysna, Plettenberg Bay, Wilderness, George, Mossel Bay, Tsitsikamma.

I built this because general AI knows Cape Town but not the difference between Buffalo Bay and Brenton-on-Sea.

## Tools
- Itinerary Generator: 3-7 day routes
- Local Knowledge: tides, lagoon, hidden beaches
- Hikes: Robberg, Tsitsikamma, Garden of Eden
- Towns: local hours, seasonal tips

## Example Prompts
"Plan 4 days in Plett - beaches + 1 hike"
"Is Knysna Lagoon safe for kids swimming?"
"Local's guide to Wilderness"
